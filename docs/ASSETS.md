# 素材交付规范（给设计 / 品牌同事）

网站里的 3D 产品 = **程序生成的罐/瓶** + **你们给的标签平铺图**。所以素材质量 ≈ 最终质感。按下面的格式给，Codex 就能直接接入（任务 T02 / T04）。

## 1. 标签平铺图（每个 SKU 一张）— 对应任务 A01

| 项 | 要求 |
|---|---|
| 内容 | **完整一圈**的标签展开图（从背面接缝剪开摊平），不要只给正面 |
| 方向 | **正面主视觉在图的水平正中**；接缝在图的最左/最右边缘（绕上去后落在背面） |
| 裁切 | 只保留标签本身，**不要**出血、裁切线、刀版线、标注 |
| 比例 | 宽 : 高 = (π × 瓶身直径) : 标签高度。和实物刀版一致即可，别拉伸 |
| 尺寸 | 宽 4096px（最低 2048px），高按比例 |
| 格式 | PNG（无损源文件）。Codex 会转 WebP/KTX2 |
| 色彩 | sRGB，RGB 模式（不要 CMYK），文字转曲/栅格化均可 |
| 命名 | `<产品 id>.png`，id 见下表，例：`eaa.png` |
| 特殊工艺 | 烫金/镭射/哑光区域：额外给一张同尺寸**黑白蒙版**（白 = 特殊工艺区），命名 `<id>-foil.png`。没有就不给 |

> 背标（营养成分表、卖点区）很重要：第 3 幕会把产品转到背面逐条讲卖点，背标会被放大到半屏。小字请保证在 4096px 宽下清晰可读。

## 2. 包装实测尺寸表 — 对应任务 A02

每个 SKU 填一行（单位 mm，游标卡尺或刀版图读数均可）：

| 字段 | 说明 |
|---|---|
| 包装形态 | 粉剂罐 / 胶囊瓶 / 袋装 / 盒装 / 其它 |
| 总高（含盖） | |
| 瓶身最大直径 | |
| 标签下沿离瓶底 | |
| 标签高度 | |
| 瓶身颜色 + 质感 | 如：黑色哑光 / 白色亮面 / 透明琥珀 |
| 瓶盖颜色 + 质感 | 如：黑色、带竖纹 |
| 实物照片 | 正 / 背 / 左 / 右 / 俯视各一张，白底或纯色底，用来对材质和比例 |

⚠️ **袋装、盒装、异形瓶**不能程序化生成，需要单独的 3D 模型（GLB）。如果全线里有，尽早说——要么外包建模，要么该 SKU 改用 360° 序列帧方案，两者都要提前排期。

## 3. 品牌资产 — 对应任务 A03

| 项 | 要求 |
|---|---|
| Logo | SVG，单色版 + 反白版；横版字标必给，图形标可选 |
| 品牌色 | 主色、辅色的 HEX；**每个 SKU 一组主题色**（外圈色 `primary` + 中心亮色 `secondary`），直接从标签上取即可 |
| 字体 | 标题字体（粗、窄、斜体气质最接近参考站）+ 正文字体的**网页授权**文件（WOFF2）。没有授权字体就说，Codex 会用开源替代（如 Anton / Barlow Condensed，OFL 协议） |
| Favicon / 分享图 | 512×512 图标源文件；1200×630 社交分享图（可后补） |

## 4. 文案 — 对应任务 A04

按 `src/content/products.ts` 和 `src/content/site.ts` 的字段给**英文定稿**（合规审过的）：

- 每个 SKU：`name`、`category`（品类一行）、`description`（≤ 2 句）、`features` 3–5 条（每条 `title` ≤ 3 个词 + `body` ≤ 2 句，并注明这条对应背标的哪一块）
- 全站：`slogan`（1–2 行，每行 ≤ 10 个字母最佳，会被放到通屏大小）、全家福标题+一句话、FAQ 5–8 组、收尾品牌陈述、页脚法律主体与免责声明

## 5.（可选）声音 — 对应任务 A06

环境底噪循环 1 条（≥ 30s 无缝）、切换产品音效、转场音效。WAV/MP3 均可，需有商用授权。

## 6. 交付方式

全部放进仓库的 `assets-inbox/` 文件夹（或网盘链接贴到对应 PR），目录：

```
assets-inbox/
  labels/        eaa.png, eaa-foil.png, ...
  packaging.xlsx 尺寸表
  photos/<id>/   实物照片
  brand/         logo.svg, fonts/, colors.txt
  copy.docx      文案定稿
```
