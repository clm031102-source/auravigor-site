# 验收与上线清单

> 用法：§1 每个 PR 都过一遍；§2–§4 在对应里程碑结束时过；§5 在文案定稿（A04）时过；§6 上线当天过。

## 1. 每个 PR（Alan 验收用，5 分钟版）

- [ ] PR 标题是 `T##: …`，描述里贴了任务卡的验收项并逐条打勾/说明
- [ ] CI 绿（`npm run check` 通过）
- [ ] 打开预览链接：**桌面**从头滚到尾，再从尾滚回头，没有卡住、闪烁、文字重叠
- [ ] **手机**打开预览链接同样过一遍
- [ ] 首屏切换 2–3 个产品后再往下滚，第 2 幕是刚选的那个产品
- [ ] 浏览器控制台没有红色报错
- [ ] 只改了任务卡"范围"里的文件；`docs/TASKS.md` 状态表已更新
- [ ] 没有新增未说明的依赖；没有新增第三方网络请求
- [ ] 页面上没有出现 Codex 自己编的产品文案

## 2. 素材验收（M1）

- [ ] 每个 SKU 的标签图：完整一圈 / 正面居中 / 无出血刀线 / 宽 ≥ 2048px / sRGB
- [ ] 背标小字在第 3 幕半屏放大时清晰可读
- [ ] 包装尺寸表齐全；3D 比例与实物照片比对无明显偏差（盖高、肩部、标签位置）
- [ ] 每个 SKU 主题色已从标签取色，且白字在其上清晰（对比度 ≥ 4.5:1）
- [ ] Logo SVG、字体 WOFF2 + 网页授权已归档
- [ ] 全线没有遗漏的袋装/异形 SKU（有则已确定 GLB 或替代方案）

## 3. 逐幕视觉验收（M2，对照 `docs/REFERENCE.md`）

- [ ] **幕 1 选品环**：拖拽有惯性会吸附；无限循环看不到产品横飞；底部名称同步
- [ ] **幕 2 揭示**：主题色从中心铺开无色带；其余产品退场干净；文案不压到产品
- [ ] **幕 3 卖点**：每条卖点对准标签对应区域并高亮；圆点同步；来回滚动不乱序
- [ ] **幕 4 口号**：口号在产品**后面**；一屏内放得下、不被裁切
- [ ] **幕 5 全家福**：依次入列；一屏放得下；可点选
- [ ] **FAQ / Outro**：产品离场后不与文字重叠；页头在深色内容上可读
- [ ] 任意位置刷新页面，恢复后的画面与滚动位置一致
- [ ] 快速滚动（触控板猛划）全程不出现错帧或半透明残留

## 4. 性能 / 兼容 / 无障碍（M4）

**性能预算**

| 指标 | 目标 |
|---|---|
| 首屏 JS（不含 3D chunk，gzip） | ≤ 130 KB（骨架现状 ≈ 115 KB） |
| 3D chunk（gzip） | ≤ 300 KB（骨架现状 ≈ 278 KB） |
| 首屏贴图总量 | ≤ 2.5 MB |
| LCP / CLS（移动端模拟） | < 2.5s / < 0.05 |
| 帧率 | 中端笔记本集显 60fps；2020 年后中端手机 ≥ 45fps |

**兼容矩阵（最近两个大版本）**

- [ ] Chrome / Edge（Win、Mac）
- [ ] Safari（Mac、iOS）
- [ ] Firefox
- [ ] Android Chrome；三星浏览器
- [ ] 无 WebGL / 低电量模式 / 省流量模式 → 降级视图可读

**无障碍**

- [ ] 纯键盘可完成全部操作；焦点可见
- [ ] 读屏按顺序读到全部产品信息
- [ ] `prefers-reduced-motion` 下无大幅运动
- [ ] axe 0 个 serious / critical

## 5. 合规（⚠️ 以下是需要**你们合规/法务确认**的检查点，不是法律意见）

站点面向海外英文市场、品类是膳食补充剂，文案风险远高于参考站那种饮料。Codex 被明令禁止自己写功效文案，所有表述以 A04 定稿为准。

- [ ] **先定目标市场**（美国 / 英国 / 欧盟 / 其它）。不同市场可用表述不同，页脚免责声明也不同
- [ ] **美国**：不出现疾病声称（治疗、预防、缓解某疾病）；如使用"结构/功能声称"，页面需带 FDA 免责声明，且此类声称有相应的备案与证据要求——请合规确认每一句属于哪一类
- [ ] **英国 / 欧盟**：健康声称只能用官方获批清单里的表述；氨基酸类产品（EAA / 精氨酸 / 谷氨酰胺）可用的获批声称非常少——请合规逐条核对
- [ ] 不出现前后对比、保证效果、"临床证明"等无出处表述；引用研究需有可公开的来源
- [ ] 若展示运动员/达人：注明合作关系；不使用其个人效果作为普遍效果的暗示
- [ ] "第三方检测 / Informed Sport / GMP / 无禁药"等字样，只在持有对应证书时使用，并能出示
- [ ] 成分表、每份含量与实物标签完全一致（网站与标签不一致本身就是风险）
- [ ] 产品名、口号不含疾病或药物暗示
- [ ] 隐私：用无 Cookie 统计则无需横幅；一旦接入广告像素/GA，需同意管理（GDPR / UK GDPR / 加州）
- [ ] 字体、图标、音效、图片均有商用授权并留档
