## 我们借鉴什么、不借鉴什么

**借鉴（通用交互范式）**：固定画布 + 滚动叙事；选品环；主题色铺屏；产品转向讲卖点；口号压在产品后；全家福收尾。

**不照搬（对方的品牌资产）**：Logo、罐身设计、字体、配色、口号（"ZERO BULLSHIT"）、文案、图标。视觉语言要长成 AuraVigor 自己的——这也是为什么口号、字体、主题色全部做成了可替换的内容/令牌。

## 和参考站的结构性差异（设计时要记住）

1. **参考站是"一个产品 × N 个口味"，包装完全相同；我们是"N 个不同产品"**，罐和瓶大小形态不一。所以走位按真实比例摆放，小瓶不强行放大到和大罐一样。
2. **我们没有 3D 模型，只有标签平面稿** → 程序化旋转体 + 标签贴图。优点是零建模成本、换标签即换产品；限制是袋装/异形包装做不了（需 GLB）。
3. **卖点因产品而异**：每个 SKU 自带 `features[]`，条数可以不同。
4. **保健品合规**：参考站可以随便写"少糖/天然"，我们的每一句都要过合规（见 `docs/CHECKLIST.md` §合规）。
